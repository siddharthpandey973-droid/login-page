# Login & Logout Page Animation 🔐

This project is a fully animated **Login and Logout Page** built using **HTML**, **CSS**, and **JavaScript**.  
It features smooth transitions, elegant UI elements, and dynamic login/logout functionality —  
giving a realistic and professional authentication experience.

---

### ✨ **Features**
- Animated login and logout transitions  
- Clean and modern UI design  
- Real-time validation effects  
- Responsive layout for all screen sizes  
- Lightweight and fast performance  

---

### 🛠️ **Technologies Used**
- HTML  
- CSS  
- JavaScript  

---

### 💡 **How to Use**
1. Clone or download this repository.  
2. Open the `index.html` file in your browser.  
3. Click on the **Login** button to see the animation, and use the **Logout** option to experience the transition effect.
